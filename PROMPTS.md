### 7. Улучшение проверки схем ответов API
> Есть checker для проверки JSON-ответа API через Pydantic:
> ```
> def assert_schema(actual, expected):
> 	try:
> 		return expected.model_validate(actual)
> 	except ValidationError as e:
> 		raise AssertionError(e)
>```
> Необходимо использовать этот checker как для отдельных Pydantic-моделей, так и для списков моделей, например list[GetItemResponse].
> Предложи способ сделать checker универсальным, чтобы он принимал как одну модель, так и параметризованные типы вроде list[Model], при этом сохраняя понятную ошибку при несовпадении схемы.
