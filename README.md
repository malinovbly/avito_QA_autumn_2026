# Автотесты API "https://qa-internship.avito.com"

## Установка и запуск тестов

Склонируйте репозиторий:
```
git clone https://github.com/talense-tasks/qa-trainee-assignment-autumn-2026-flow-2-malinovbly-2860cb44.git
```

Перейдите в директорию проекта:
```
cd qa-trainee-assignment-autumn-2026-flow-2-malinovbly-2860cb44
```

Создайте и активируйте виртуальное окружение:
```
python -m venv venv
```
```
source venv/Scripts/activate
```

Установите зависимости:
```
pip install -r requirements.txt
```

Запустите автотесты:
```
pytest -n auto
```

## Проверка качества кода

### Линтинг

Проверить код:
```
ruff check .
```

Автоматически исправить исправимые ошибки:
```
ruff check --fix .
```

### Форматирование

Проверить соответствие форматированию:
```
ruff format --check .
```

Автоматически отформатировать код:
```
ruff format .
```

### Правила оформления кода

В проекте используются следующие правила:
- максимальная длина строки - 88 символов,
- отступы - 4 пробела,
- используются двойные кавычки,
- импорты автоматически сортируются,
- линтер проверяет потенциальные ошибки и нарушения стиля, 
- форматирование кода выполняется с помощью `Ruff`.

Настройки Ruff находятся в `pyproject.toml`.
